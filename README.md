# Mixer

macOS에서 앱별로 소리 크기를 조절하는 메뉴바 앱입니다. MacBook의 노치를 클릭하면 믹서 패널이 펼쳐집니다.

- 소리를 내는 앱마다 볼륨 슬라이더(0~200%)와 음소거 버튼
- 슬라이더 가운데가 원래 소리(100%). 100%를 넘기면 리미터로 소리가 깨지는 것을 막으며 키웁니다
- 앱별 볼륨을 기억했다가 그 앱이 다시 소리를 낼 때 적용합니다
- 노치가 없는 화면(외장 모니터, 클램셸 모드)에서는 메뉴바 아이콘으로 같은 패널을 엽니다
- 가상 오디오 드라이버를 설치하지 않습니다(Core Audio Process Tap 사용)

## 요구 사항

- macOS 14.4 이상
- Swift 6 툴체인(Xcode 16 이상 또는 Command Line Tools)

## 설치

```sh
git clone https://github.com/min2e-crypto/mixer.git && cd mixer && scripts/build-app.sh
```

빌드가 끝나면 `~/Applications/Mixer.app`에 설치되고 바로 실행됩니다.

## 업데이트

```sh
cd mixer && git pull && scripts/build-app.sh
```

다시 빌드한 앱은 시스템 오디오 녹음 권한을 한 번 더 묻습니다. 허용하면 됩니다.

## 처음 실행

1. 메뉴바에 슬라이더 아이콘이 나타납니다. 처음 실행할 때 로그인 시 자동 실행으로 등록됩니다(패널의 "로그인 시 실행"으로 끌 수 있습니다).
2. 처음으로 앱 볼륨을 바꾸면 **시스템 오디오 녹음** 권한을 묻습니다. 허용해야 동작합니다.
   거부했다면 시스템 설정 → 개인정보 보호 및 보안 → 시스템 오디오 녹음에서 Mixer를 켜 주세요.

## 사용법

- 노치를 클릭하면 패널이 펼쳐지고, 바깥을 클릭하거나 Esc를 누르면 닫힙니다.
- 메뉴바 아이콘을 눌러도 같은 패널이 열립니다.
- 슬라이더를 가운데(100%) 근처로 놓으면 100%에 붙고, 이때는 그 앱의 소리에 전혀 개입하지 않습니다.

## 알아 둘 점

- 볼륨이 100%가 아닌 앱은 소리를 가로채 다시 출력하므로 약간의 지연(수 ms~십수 ms)이 생기고, 다채널 소리는 스테레오로 합쳐집니다.
- DAW(Logic, Ableton 등), Zoom, Teams는 가로채면 문제가 생겨 조절 대상에서 제외됩니다.
- Discord 볼륨을 100%가 아닌 값으로 둔 채 소리 포함 화면 공유를 하면, 통화 소리가 상대에게 다시 들어갈 수 있습니다.
- Safari처럼 별도 helper 프로세스로 소리를 내는 앱을 묶기 위해 macOS 비공개 함수를 씁니다. OS 업데이트로 사라지면 해당 소리가 앱 이름 대신 helper 이름으로 보일 수 있습니다.
- 슬립 복귀 직후 소리가 끊기면 그 앱 볼륨을 100%로 되돌렸다가 다시 조절해 주세요.

## 삭제

```sh
pkill -x Mixer
rm -rf ~/Applications/Mixer.app
```

시스템 설정 → 개인정보 보호 및 보안 → 시스템 오디오 녹음, 일반 → 로그인 항목에 남은 Mixer도 지울 수 있습니다.
